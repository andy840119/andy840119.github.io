# 步驟二: 寫初稿

使用者說「圖片貼上去了，幫我寫完」時執行。寫作風格照 [style.md](style.md)。

## 使用者會怎麼準備

使用者會直接在 `index.md` 裡貼好圖片，圖片的順序就是文章的順序。圖片附近可能會有:

| 使用者寫的內容 | 要怎麼處理 |
|---|---|
| 只有圖片，沒有文字 | 看圖說故事，寫一到幾行說明 |
| 圖片下有簡短的文字(例如「特快車」、「測試」) | 保留原句，再根據圖片和上下文補充 |
| 圖片以外的補充資訊(價格、心得、經驗) | 照使用者的意思寫進文章，不要改掉事實 |
| 明確寫給 AI 的指示(例如「Claude 幫我寫一下前言」) | 照著做，做完把這行指示拿掉 |
| 步驟一留下的 `<!-- TODO -->` | 有足夠資訊就寫掉並刪除 TODO；資訊不夠就保留 |

## 步驟

1. 重新讀一次 `index.md`，以使用者目前寫的內容為準。
2. 列出 `res/` 內的圖片，確認文章裡引用的檔案都存在。檔名通常是截圖時間 `YYYY-MM-DD-HH-MM-SS.png`。
3. 實際看過每一張圖片(工具沒辦法讀圖片的話，就請使用者描述)。可以從圖片上讀到的資訊(說明書上的尺寸、招牌上的店名、面板上的數字)可以直接用。
4. 照圖片順序把文章寫完:
   - 不要調整使用者排好的圖片順序，也不要刪掉使用者寫的句子
   - 優缺點、結論可以先根據文章內容整理幾點，其他留 TODO
   - 需要連結舊文章的地方用相對路徑

## 回報

- 哪些內容是照使用者的補充寫的、哪些是看圖寫的
- 從圖片推測、需要使用者確認的地方
- 留下的 TODO 清單
